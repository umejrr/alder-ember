# Photographs: the originals as received

Status (22 October 2026): the first set of photographs supplied by the owner is here and is on the site (see `notes.txt`). New photographs from a shoot go in this folder in the same way.

Upload the finished photographs here. A scheduled run places them on the site, checks them, and publishes the preview.
Nothing in this folder is published as it is: the site only ever serves the resized copies the run builds.

## How to name each file

Use the slot name from the photography brief, then `_` and a number. Extra frames (`_02`, `_03`) are welcome: the best one is chosen.
The model in the file name is treated as the model the photograph shows, so only name a file `alder-...` if it shows the Alder.

| File name | What it is |
|---|---|
| `rowan-exterior_01.jpg`, `alder-exterior_01.jpg`, `ember-exterior_01.jpg` | The model from outside |
| `rowan-interior_01.jpg`, `alder-interior_01.jpg`, `ember-interior_01.jpg` | The model's interior |
| `rowan-detail_01.jpg`, `alder-detail_01.jpg`, `ember-detail_01.jpg` | The model's detail frame |
| `detail-timber_01.jpg` (and `detail-timber-vertical_01.jpg`) | Exterior cladding close-up |
| `detail-interior-finish_01.jpg` | Interior timber and bench edge |
| `detail-construction_01.jpg` | Insulated wall build-up (from the manufacturer) |
| `detail-glazing-heater_01.jpg` | Glazing frame, handle, heater |
| `site-access_01.jpg` | A real site and access check |
| `installation-process_01.jpg` | A real installation in progress |
| `closing-warmth_01.jpg` | The closing image for the home page |
| `social-share_01.jpg` | Link-preview image, 1200 × 630 or larger, text-free |

## Size and format

JPEG, sRGB, **3000 to 4500 px on the long edge, under 5 MB each**. Keep the full-size originals and the RAW files yourself:
the site never serves more than about 1900 px wide, and very large files make the repository slow for everyone.

## Optional: `notes.txt`

Put a `notes.txt` in this folder with the photographer's name, the licence terms, and anything about which sauna or configuration
appears in which file. It is recorded with each approval. Without it the record says only that the owner confirmed the photographs.

## Please do not upload

RAW files, photographs with identifiable faces, visible brands or logos, competitor products, or house numbers and number plates.
Any file like that is held back and reported, not published.
