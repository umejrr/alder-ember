## Open decisions recorded in the content

- **Changing area (Ember):** the supplied table describes the Ember "with a changing area" and the option list also names a changing area. Whether it is included, optional or a separate configuration is unresolved, so no paid changing-area option exists and the site says it is still being confirmed.
- **Option compatibility:** glazing upgrades, exterior finishes, alternative heaters, Wi-Fi controls, backrests, lighting and entrance platforms have no compatibility matrix or price, so none is selectable on any model.
- **Quotation journey:** all core models use a quotation. The brief places core-sauna online ordering in a later phase, so there is no direct-buy route.
- **Founder profile:** no biography, headshot or quotes were supplied, so the About page describes roles only.
- **Technical claims:** no heater brands, outputs, running costs, warm-up times or manufacturer names are published.

## Not to be done merely because the prototype is finished

Do not publish a public site, enable live payments, or send live customer or CRM notifications until the actual agreed environment and authorisation exist.
